<analysis>**original_problem_statement:**
The user wants to build a valet parking platform called SwiftValet.

**PRODUCT REQUIREMENTS:**
- **User Roles:**
    - **Customer:** Interacts via WhatsApp, no app needed.
    - **Valet Driver:** Uses a React PWA for intake, scanning, logging, and GPS pinning. Logins via OTP.
    - **Admin:** Manages valet drivers (add/delete), tracks tips, and views all car statuses for their specific client (e.g., a restaurant). Logins via OTP.
    - **Super Admin:** A top-level role that can add/manage Admins for different clients and view platform-wide analytics. Logins via email/password.
- **Functional Requirements:**
    - **Phase A: Intake & Parking**
        - Quick Intake: Valet enters Phone Number, License Plate, and a physical Tag Number.
        - The intake is a 2-step process: 1. Car Handoff (Phone, Plate), 2. Parking Location (GPS, Landmark, Tag Number).
    - **Phase B: Retrieval & Claiming**
        - Customer replies RETR to the WhatsApp message to create an Open Ticket.
        - A push notification is sent to all active valets. The first to claim gets the ticket.
    - **Phase C: The Ghosting Protocol**
        - 5-Minute Rule: A timer starts when the car arrives. If the customer doesn't show up, the valet can return the car to a parking spot.
    - **Phase D: Handover & Gratuity**
        - Valet marks handover as complete and a tipping link is sent.
    - **Admin & Super Admin Features:**
        - Admins can add their name, their client's name, and a profile photo.
        - Super Admins have a dashboard to view platform analytics and manage clients (admins).
        - Admins have a dashboard to view operational stats (valets, vehicles, tips).
- **Recent User Requests (Implemented):**
    - Implement a detailed Nightly Pulse reporting dashboard for Admins.
    - Fix OTP login by always displaying the OTP on screen as a fallback.
    - Implement delete functionality for Admins (by Super Admin) and Valets (by Admin).
    - Add collapsible sections to the Admin Panel.
    - Add per-client reporting and delete functionality for Super Admins.
    - Create an archive section for deactivated clients in the Super Admin panel.
